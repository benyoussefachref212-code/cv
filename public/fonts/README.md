Place the webfont files here so the app can embed them for PDF export and preview.

Expected files (woff2):
- Merriweather-Regular.woff2
- Merriweather-Bold.woff2

How to obtain:
- Download Merriweather woff2 files from Google Fonts or another trusted source.
- Rename them exactly as above and place them in this folder.

Once added, the CV preview and PDF export will use these local fonts for the `classic` template.
